Welcome to my personal portfolio repository! Designed from scratch with a heavy focus on fluid UI/UX, premium glassmorphism aesthetics, and interactivity, it serves as a central hub to showcase my experience, projects, and personal interests.

## ✨ Features

- **Dynamic Interactive Web Piano 🎹**: A fully functional, playable web piano built with `Tone.js`. It features an integrated MIDI playback system that parses and plays a custom 1300-note array, complete with simulated sustain pedals and an aesthetic glassmorphic interface.
- **Bespoke UI/UX**: Custom interactive cursor particle trails, smooth scroll-linked animations, dynamic responsive layouts, and premium dark-mode aesthetics.
- **Project Showcases**:
  - **Gold Dashboard**: Driver-based attribution engine and AI-assisted scenario analysis converting macroeconomic narratives into structured directional signals.
  - **Reddit Stock Predictor**: Scalable data ingestion pipeline and modular backend processing 115k+ Reddit posts for low-latency sentiment analysis.
  - **Harmony Massage Clinic**: Production MERN-based clinic application featuring secure Google Calendar API integration.
- **Experience Highlights**: Clean, accessible timelines of my professional journey at 3MA Consulting and Barcoded Fit Tech.

## 🛠️ Tech Stack

- **HTML5 & CSS3**
- **Tailwind CSS** – Extensively utilized for rapid styling and creating the deep, vibrant glassmorphic dark theme.
- **Vanilla JavaScript** – Powers all the scroll physics, particle physics, and UI interactions without the overhead of heavy frameworks.
- **Tone.js** – A Web Audio framework used to synthesize and play the Salamander Grand Piano samples with high-quality reverb nodes.

## 🚀 Getting Started

If you want to poke around the code or run this locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/leobyang/Personal_Portfolio.git
   ```
2. Because of CORS policies with loading the `.mp3` audio samples for Tone.js, you must serve this project over a local web server (simply opening `index.html` as a file might block the audio). 
   - The easiest way is using the **Live Server** extension in VSCode.
   - Alternatively, you can run a Python HTTP server in the root directory:
     ```bash
     python3 -m http.server 8000
     ```
